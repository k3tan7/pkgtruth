Understanding Release DNA

Historical Context
What does "baseline" mean?

A baseline is the reference release you choose to observe what changed. If your baseline is older than the target, pkgtruth runs a forward evolution check. If it is newer, pkgtruth explicitly describes a reverse comparison.

What Release DNA tracks:

  • First-observed startup directives: When .pth files or customization modules first appear.
  • First-observed capabilities: When network sockets or subprocess calls are introduced.
  • Entry points & command changes: When console scripts are added, removed, or pointed elsewhere.
  • File inventory shifts: Added, modified, or dropped modules.
Deterministic fact, not ML inference: "First observed" strictly means absent from the selected baseline. It does not claim global novelty across all uninspected historical packages.
